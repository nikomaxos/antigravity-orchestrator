# Multi-Model & Multi-CLI Delegation Skill (5-Tier / 4-Pool Playbook)

## 1. Why This Architecture Exists (Pure Zero-Hands-On Orchestrator Invariants)
1. **Default Orchestrators are `Orchestrator (Carbon -> Hydrogen)` & `Orchestrator (Neon -> Hydrogen)`**: Flagship planning turns run on `Carbon` (or `-25%`-cost `#2` Steerability planning on `Gemini 4 Neon`), staying pure & ultra-thin (`<35K–60K` tokens), while `exit_plan_mode` hands execution automatically to **`Gemini 4 Hydrogen`** (`19%` faster, `~24%` less quota overall than Carbon alone).
2. **`Gemini 4 Neon` bridges `Hydrogen` speed and `Carbon` depth**: **`Gemini 4 Neon`** scores **65.2%** on Terminal-Bench 4.1 (`#2` Agent Arena Index & `#2` Steerability, `0.0%` shortcut rate, `39.0%` SWE-sweep, AA Intelligence `61` at `xhigh`) at **`$3/$15` (-25% vs Carbon `$4/$20`)**, making it the primary Pool A escalation target for **`T3` multi-file backend/refactoring (`High`)**, **`T2` high-steerability UI (`Low/Medium`)**, and **`T4` complex multi-file SWE (`XHigh`)**.
3. **`Gemini 4 Hydrogen` replaces `Gemini 3.8 Flash` across ALL execution, coding, triage, live-ops/pre-flight & gates**: `Gemini 4 Hydrogen` is up to **2.5x faster**, scores **~57.0% vs 18.2%** on Terminal-Bench 4.1 (**>3x leap**), cuts hallucinations by **>5x**, uses **~23% fewer tokens**, and supports native parallel tool batching (`2x` per-token rate -> `~1.5x` net cost for `3x` quality). **`Gemini 3.8 Flash` (`invoke_subagent(Model="flash")`) is restricted STRICTLY to the `browser` subagent only** and is **EXPLICITLY FORBIDDEN** for all non-browser tasks (`T1` exploration, live-ops/production pre-flight checks, API/DB/hardware/modem/SMPP queries, worker checks, scripts, code verification, or bulk log scans — for complex multi-step browser flows, even `browser` may use `Model="inherit"` on `Hydrogen`).
4. **Orchestrator Step-0 Pre-Flight & No `Model: "flash"` Downgrade**: During an `Orchestrator (Carbon/Neon/Argon)` planning turn, **NEVER** spawn an intermediate `invoke_subagent(Model="flash")` (`3.8 Flash`) for pre-flight verification — instead hand off directly via `exit_plan_mode` into **`Gemini 4 Hydrogen`** with an explicit **Step 0: Read-Only Pre-Flight Check** and a strict **`Re-plan if:`** guard (stop before mutating/production actions if state/bitmasks/APIs deviate). Inside any `Hydrogen` execution turn, execute directly (or with `Model: "inherit"` / `swarm`), never calling `invoke_subagent(Model="flash")`.
5. **Never use `Carbon High` for I/O exploration & never exceed `120K–160K` parent tokens**: Rotate via `/compact` or `.agent-reports/handoff-latest.md`.
6. **Antigravity is the SINGLE WRITER**: External CLIs (`codex`, `claude`, `opencode`) are strictly **read-only** analysts/patch-producers in gated workspaces (`protect-enforcement.sh` blocks write flags).

## 3. Pure Zero-Hands-On 5-Tier Task Routing Matrix (`T0` – `T4`) & External-First Frontier Offload

- **Universal Frontier Parent Orchestrator (`Orchestrator (Carbon -> Hydrogen)` / `Orchestrator (Neon -> Hydrogen)` / `Gemini 4 Carbon Medium` default, or `Gemini 4 Neon` / `Gemini 4 Hydrogen` / `Claude 5.5` in UI Dropdown)**: Pure conversational triage and planning (0 direct codebase reads/edits/builds during `Carbon`/`Neon`/`Argon`/`Claude` planning turns). When `exit_plan_mode` hands execution to **`Gemini 4 Hydrogen`**, execute directly without downgrading to `Model: "flash"`.
- **External-First Frontier Offload (`frontier-orchestrate.sh`)**: To prevent `Pool A` (`Gemini 4`) from running out of quota while `Pool B` (`Codex`), `Pool C` (`Claude`), and `Pool D` (`DeepSeek`) still have credits, run `bash .agents/scripts/frontier-orchestrate.sh --tier <ui|backend|deep>` inside the **`Gemini 4 Hydrogen`** execution turn (or via `swarm` `gemini-4-hydrogen-low|medium`, NEVER `Model: "flash"`) so **Pools B/C/D perform the heavy frontier reasoning & patch design FIRST**, and **`Gemini 4 Hydrogen`** applies edits, runs tests, and executes gates. Fall back to native **`Gemini 4 Hydrogen` (`Medium`/`High`)**, **`Gemini 4 Neon` (`High`/`XHigh`)**, or `Model: "pro"` (`Carbon High`) loops when `frontier-orchestrate.sh` exits `2`.
- **`T1` Exploration, Live-Ops Pre-Flight, Log Slicing & Docs (`Gemini 4 Hydrogen Low` / `swarm`, or `Gemini 4 Hydrogen Medium` for critical live production GSM/SMPP/bitmask checks; Pool D `DeepSeek-Flash` via `frontier-orchestrate.sh --tier flash` for massive non-critical `100K+` log dumps)**: Multi-file grep/read, live-ops pre-flight (directly in `Hydrogen` execution turn with `Re-plan if:` guard in `Orchestrator` mode), log extraction, read-only DB/API telemetry checks, `SKILL.md` / docs drafting (`<1,000` tokens structured findings). **`Gemini 3.8 Flash` (`Model: "flash"`) is STRICTLY FORBIDDEN outside the `browser` subagent.**

  - Calls `bash .agents/scripts/frontier-orchestrate.sh --tier ui --prompt "<task>"` (cascading **Pool C `Claude Sonnet 5.5 med` -> Pool B `Codex gpt-6.1-terra med / sol` -> Pool D `DeepSeek-V4-Pro`**), then applies and verifies via **`Gemini 4 Hydrogen Medium`** (or **`Gemini 4 Neon Low/Medium`** for high-steerability UI state) while strictly preserving project design systems.   - Calls `bash .agents/scripts/frontier-orchestrate.sh --tier backend --prompt "<task>"` (cascading **Pool B `Codex gpt-6.1-sol high / astra` -> Pool C `Claude Sonnet 5.5 high` -> Pool D `DeepSeek-V4-Pro`**) + Stage-0 DeepSeek precheck + `R2` Cross-Model Review Gate + live API verification.
